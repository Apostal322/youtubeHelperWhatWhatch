# Benchmark reports

Generated by `avd bench` (see `docs/evaluation.md`). Scratch runs are git-ignored; curated
baselines (`baseline-*`) are committed so regressions are visible in review.

| Report | Evaluator | Dataset | Labels |
|---|---|---|---|
| `baseline-heuristic-synthetic_v1.{md,json}` | deterministic heuristic baseline | synthetic_v1 (20 synthetic videos) | synthetic design intent, single rater |
| `retrieval-talkpython-n100-s7.{md,json}` | hashing vs MiniLM ONNX vs RRF (`avd bench-retrieval`) | 100 Talk Python transcripts (titles withheld) | creator titles as known-item queries (no human labels needed) |
| `baseline-heuristic-real_pilot_v1-dev.{md,json}` | heuristic baseline (`avd bench-real`) | real_pilot_v1, dev split (10 licensed episodes) | **none yet**: human-grounded section reports "not available" |

Notes:
* Every report starts with warnings when labels are synthetic or single-rater.
* Intra-list diversity (`ILD`) is `1 − mean pairwise cosine`; with signed-hash embeddings cosines
  can be slightly negative, so values marginally above 1.0 are possible.
* To benchmark a real model: `AVD_LLM_PROVIDER=anthropic AVD_ANTHROPIC_API_KEY=… avd bench --evaluator configured --tag llm-…`.
  Responses are cached in the run's temporary database only; costs appear under `cost`.
