# Getting help

* **Setup problems:**
  * check [`docs/local-setup.md`](docs/local-setup.md) and [`docs/self-hosting.md`](docs/self-hosting.md);
  * run `avd doctor` (backend) and the extension's *Preferences → Backend → Re-check
    connection*.

  If you still need help, open an issue with the *Setup help* template and paste the
  diagnostics (they contain no secrets).
* **Bugs:** the *Bug report* template.
* **Questions about the method** (how scores are produced, what they mean): read
  [`docs/evaluation.md`](docs/evaluation.md) first, then open a discussion issue.
* **Security issues:** see [`SECURITY.md`](SECURITY.md). Do not post them publicly.

The project has no hosted service, so there is no "the server is down". Every instance is run by
whoever installed it.
