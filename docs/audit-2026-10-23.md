# Engineering audit and release hardening, 2026-10-23

Scope: AI Video Discovery only (backend, extension, community archives, docs). Each fix below
has a regression test that fails on the code before the fix (checked by reverting only the
source change and re-running the test). **Zero verified real LLM calls**: every model response
in these tests comes from a scripted test double or the Ollama protocol mock.

Defects 32-37 were found by an independent verification of the four P0 fixes (separate probe scripts
with scripted model doubles, not the regression tests), and each one reproduced before it was fixed.

## Not fixed (documented)

* Recommender tuning findings (exploration quota at small limits, quality tie-break weight, MMR
  normalisation) were not changed: one example is not evidence for retuning.
* A single part whose notes have a summary but no quotes, among otherwise well-grounded parts, is
  labelled "(no quoted points)" in the final prompt but does not by itself trigger review: a part
  can legitimately contain nothing quotable.
* The hashing embedder's recall stays below MiniLM's on the 53-query audit set (35 vs 48 hits); MiniLM
  remains the recommendation.

## Release gates

Unchanged: **1 of 12 pass** (`injection_benign_flag_rate`, 0.0 ≤ 0.05), 7 are blocked by missing
human labels and 4 by the absence of a real model run. Re-checked on this branch by re-running
`avd bench-real --offline --split dev` and `avd gates status` (the new delimiter detector did not
flag any benign dev segment). The one passing gate does not depend on the evaluator, so it says
nothing about score validity; "no gate is evaluable for validity" is the accurate summary.
