# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work rather than people, and do not harass
anyone, in issues, pull requests, reviews or any other project space. This applies equally to
discussions of creators and videos: assessments are about content, never personal attacks on
people.

**Reporting.** Contact the repository owner privately through GitHub (for example, a private
security advisory if the issue is sensitive, or an issue asking for a private contact without
including details). Reports are handled confidentially. As of this writing the project has a
single maintainer, the repository owner; there is no separate moderation team.

**Enforcement** follows the Contributor Covenant's enforcement guidelines, from a warning up to a
ban from project spaces.
